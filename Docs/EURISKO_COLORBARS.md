# Eurisko colorbar policy

With Auto flip enabled, oxygen volume/mass fraction and soot visibility use
blue for higher values and red for lower values. Temperature retains the
upstream direction: higher values red, lower values blue. Other species,
including carbon monoxide and carbon dioxide, retain upstream behavior.

This extends the existing slice flag rather than forcing a palette direction
from a script. The global Auto flip checkbox and manual flip remain available.
The classification regression runs in both Linux and Windows Release builds.
The dedicated workflows publish portable binaries with source provenance and
SHA-256 checksums. Version: `1.17.0+sc2-eurisko.3`.
